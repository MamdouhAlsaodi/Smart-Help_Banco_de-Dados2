# Plano do Projeto — SmartHelp

1. Definir o MVP como um sistema de Helpdesk sem frontend.
2. Preparar PostgreSQL e pgAdmin com Docker.
3. Modelar usuários, categorias, chamados, soluções e tags no Prisma.
4. Criar migração e índices para consultas.
5. Implementar API Node.js para criar, consultar e resolver chamados.
6. Gerar milhares de registros fictícios com um seeder.
7. Demonstrar recuperação rápida de informações com Full-Text Search do PostgreSQL.
8. Documentar execução, uso de IA e estrutura do banco.
